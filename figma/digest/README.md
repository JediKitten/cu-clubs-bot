# CU Clubs · Дайджест

Плагин: `dfa2caf2-10bd-4d25-a85e-900859efa279`.
Собранная версия: `e2427b4414435563f8a5c2dc156432b4a5c65791` (15 ноября 2026).

## Запуск

1. В тестовом CU Clubs: «Админ-меню → Создать дайджест».
2. Выберите неделю, затем «Все открытые встречи» или «Выбрать вручную».
   Проверьте предпросмотр и скачайте JSON-файл. Публиковать файл в канал не нужно.
3. В Figma выделите обложку и страницы **одного** дайджеста 1200×1500.
   Можно выделить созданную этим плагином секцию для её обновления.
4. Откройте плагин, загрузите файл, нажмите «Проверить», затем «Создать копию».

Плагин использует только переданный файл, не делает сетевых запросов и не хранит
ключи, OAuth или файл в документе. В слоях сохраняются только небольшие служебные
метки владельца/недели/публичного ID встречи для повторного запуска.

## Результат

- Исходные страницы сохраняются. Создаётся отдельная секция с копией обложки
  и нужным числом страниц подробностей.
- Оранжевые строки заменяются встречами файла: заголовок — названия клубов,
  подробности — название встречи; полное публичное описание включается отдельно.
- По Москве: дата, время, место. Разные встречи клуба сохраняются; коллаборация
  имеет одну строку/точку. Клубные встречи дня сортируются по началу, затем ID.
- Строки остальных категорий клонируются с сохранением текста и оформления;
  в копии они переразмещаются после клубных строк того же дня.
- Оранжевые точки пересчитываются, остальные точки сохраняют цвет и положение.
- Повторный запуск на выбранной секции плагина обновляет эту копию после успешной
  сборки. Ошибка оставляет прежнюю копию и исходный выпуск на месте.

## Требования к макету и защита данных

Нужны строки с двумя колонками шириной1040 (по510, промежуток20), русская дата
с днём недели, обложка «События недели» и сетка из35 или42 чисел. Месяц обложки
должен соответствовать месяцу понедельника файла. Плагин не переписывает сетку
дат или месяц: новую обложку подготавливает редактор. Ошибку определения дат
нельзя обходить заменой старого месяца автоматически.

Основной шрифт — Graphik LC Regular/Medium. Если он недоступен, изменений нет.
Для явно выбранного черновика можно использовать Inter; это не приёмка точного
совпадения с оригиналом. В подключённом инструменте Graphik LC не обнаружен,
поэтому полное визуальное прохождение в редакторе остаётся отдельной приёмкой.

Ручной текст внутри старого списка, который не входит в распознанную строку
встречи, требует вынести его за пределы списка. Так текст не удаляется молча.
Для других категорий другой недели требуется явное разрешение в панели.

Переполнение календарной ячейки или одной страницы не обрезает события: операция
останавливается с объяснением. Файл до1МБ, до500 встреч. Публикация в Telegram,
изменение Sheets-цветов и уведомления лидерам этим плагином не выполняются.
