# CU Clubs Bot

Университетский Telegram-бот клубов ЦУ и API для клубных ботов.

## Текущее состояние

Начат этап 0: каркас Python-приложения, конфигурация, проверки здоровья,
контейнерное окружение, CI и план реализации. Пользовательские сценарии бота,
бизнес-команды, миграции, worker и внешние доставки ещё предстоит реализовать.
Наличие параметра интеграции в конфигурации не означает, что она подключена.

## Согласованный объём

- В первом продуктовом этапе: карточка клуба, каталог, почтовая верификация,
  роли и кабинет администрации.
- Далее: встречи, коллаборации, запись, API, синхронизация существующего
  календаря Google Sheets, QR, ведомости, опросы и аналитика.
- Новая база, два администратора и один стартовый киноклуб.
- Данные без автоматического удаления. Планируется ежедневная резервная
  копия в личный Telegram-чат владельца от имени бота.
- Каждый календарный год использует отдельный лист `Calendar YYYY`;
  оформление существующего календаря сохраняется.

## Локальный запуск

Требуется Python 3.12 и uv.

```sh
uv sync --locked
cp .env.example .env
uv run python -m cu_clubs api
```

Адрес приложения — `http://127.0.0.1:8000`, схема OpenAPI — `/openapi.json`.
Проверка liveness не требует внешних сервисов, readiness проверяет доступность
PostgreSQL. Без подключённой БД отрицательный результат readiness ожидаем.

Проверки проекта:

```sh
uv run pytest
uv run ruff check .
```

Точные команды контейнерного запуска и переменные доступны в `compose.yaml`
и `.env.example`. Рабочие секреты хранятся вне Git. По умолчанию внешняя
доставка отключена; локальное приложение не отправляет письма, сообщения
и изменения в рабочий календарь.
