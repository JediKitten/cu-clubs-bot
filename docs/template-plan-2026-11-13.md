# Доработка шаблонов встреч

## Границы

Владелец поручил сверить сделанное с двумя спецификациями и продолжить только
шаблоны. FAQ и настройка почты явно отложены. Синхронизация Sheets, посещаемость,
опросы, аналитика, интеграционный API и другие подсистемы в эту работу не входят.

Основание: `specification.md`, раздел 7, особенно описание шаблонов;
`development-spec.md`, раздел создания встреч; текущий сервис и интерфейс.
Полный срез соответствия проекта хранится в отдельном файле аудита.

## Уточнения владельца

- Название встречи и текст после регистрации также копируются в шаблон.
- Можно сохранить время проведения, чтобы для следующей встречи менять только
  дату: отдельное время начала по Москве и длительность. Старую календарную дату
  и срок регистрации не переносим. Время в шаблоне можно убрать или изменить.
- Команда каждого клуба-соорганизатора может сохранить шаблон в свой клуб.
  Наличие прав на другой, не участвующий во встрече клуб не делает его получателем.
- Публичная команда клуба сама по себе не даёт права работать с шаблонами.

## Обнаруженные разрывы

| Требование | Состояние до доработки | Что меняем |
|---|---|---|
| Шаблоны → карточка → создать, изменить, переименовать, удалить | Список сразу создавал встречу; управления не было | Отдельная карточка и все четыре действия |
| Перенос длительности | Поле сохранялось, но отбрасывалось при создании черновика | Сохраняем подсказку в черновике и рассчитываем окончание после выбора даты |
| Из шаблона заполняются типовые данные | Мастер повторно запрашивал все поля | Показываем заполненный черновик; выбирается дата, остальные поля можно поправить |
| Общие шаблоны команды, три независимых права | Только управление встречами даёт доступ | Проверяем это право при каждом чтении и изменении, включая старые кнопки |
| Удаление с подтверждением, без потери истории | Был только метод soft delete | Подтверждение с текущей версией; скрываем удалённый шаблон, сохраняем историю |
| Повторное использование имени после удаления | Общий UNIQUE запрещал его | Уникальны только активные имена; гонка возвращает понятную ошибку |
| Совместные встречи | Сохранение разрешалось только в клуб инициатора | Показываем только участвующие клубы, которыми управляет данный пользователь |

## Распределение задач

| Исполнитель | Зона | Результат |
|---|---|---|
| Агент ядра `template_domain` | `events.py`, `event_models.py`, миграция 0005, тесты сервиса | Версионированные операции шаблонов, переносимые поля, права, аудит, длительность и время |
| Агент интерфейса `template_interface` | Новый `template_ui.py`, тесты диалогов | Список, карточка, предпросмотр правок, переименование и подтверждение удаления |
| Технический лид | Интеграция обработчиков, меню клуба, создание встречи из шаблона | Одно окно; заполненный черновик; выбор новой даты с сохранённым временем |
| Независимый контролёр совместимости | Аудит ТЗ, прав, исходных текстов и регрессий | Отдельный отчёт, проверка перед выпуском |

## Порядок и приёмка

1. Зафиксировать контракты и миграцию, согласовать спорные свойства с владельцем.
2. Завершить сервис и интерфейс независимо, затем соединить их в текущей навигации.
3. Проверить на отдельном PostgreSQL: изменение коллегой, устаревшие кнопки,
   отзыв прав, доступ другого клуба, одновременные одинаковые имена, удаление,
   сохранность ранее созданных встреч и переход даты через полночь.
4. Прогнать подходящие проверки проекта и независимый review. Сохранить точные
   тексты общих сценариев и все существующие изображения.
5. Обновить тестовый экземпляр с резервной копией и проверкой миграции/здоровья.

После изменения шаблона уже созданные встречи остаются самостоятельными.
Новая встреча получает новую ссылку, пустую регистрацию и отсутствие согласия
партнёра; создание черновика не публикует встречу и не рассылает анонс.

## Результат проверки перед выпуском

Операции сервиса, интерфейс и создание встречи с выбором только новой даты
реализованы. Общий прогон проекта с PostgreSQL: **236 passed**, без пропусков;
Ruff и форматирование прошли. Независимый контролёр принял пакет после проверки
прав, версий, изоляции копий, времени, удаления и сохранения исходных текстов.

В [аудите проекта](audit-2026-11-13.md) большая таблица описывает исходный
срез `39cbab1`; перечисленные там пробелы шаблонов закрываются этим пакетом.
Остальные частичные или не начатые функции не реализовывались в его рамках.
