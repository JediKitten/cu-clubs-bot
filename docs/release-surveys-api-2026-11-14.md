# Опросы, аналитика, API и завершение UX-пакета

Включено прямым поручением владельца 14 ноября. Почта и полный FAQ отложены.

- Конструктор анкеты клуба/встречи: неизменяемая первая оценка 1–5, текст,
  один/несколько вариантов и шкала 1…N. Версии и прежние формулировки сохраняются;
  у коллаборации одна анкета со снимком анкеты инициатора.
- Отвечают фактически пришедшие после окончания. Первая оценка сохраняется сразу,
  не перезаписывается повтором; незавершённые ответы можно продолжить. Позднее
  посещение/подключение профиля обнаруживает worker, приглашения не дублируются.
- Частная аналитика лидера/администратора: средняя по исходным оценкам и число
  ответов, встречи/посещения/охват, доходимость по составу на начало, отмены до
  начала и визиты без записи, периоды/произвольные даты/обратная связь. Совместная
  встреча учитывается по одному разу в университетском итоге.
- API: ключи/scopes/отзыв, явное согласие студента, одноразовый обмен, общие
  команды EventService/AttendanceService, If-Match, идемпотентность, курсор,
  подписанные webhooks со статусами/повторами. [Контракт](api-integration.md),
  [независимая проверка](api-security-review-2026-11-14.md), пример клиента в examples.
- UX: возвраты auth/QR/ручной отметки/Excel, сохранение периода отчёта, группы
  шаблонов, гибкое время шаблона, отзыв старых кнопок при смене предпросмотра.

Входы: меню → «Опросы после встреч»; клуб → «Настройки клуба → Опрос клуба /
Интеграции»; клуб → «Аналитика»; карточка встречи → «Опрос встречи / Аналитика»
для лидера, «Оценить встречу» для фактически пришедшего после окончания.

Границы: общий атомарный черновик всей карточки клуба не добавлялся; остальные
UX-запросы отмечены в аудите. API доступен через server localhost:8310 или
SSH-туннель, внешний HTTPS пока не настроен. Не заявляется подключение реального
независимого клубного бота или внешний pentest; тесты используют синтетические данные.
При слиянии профилей с ответами на одну встречу операция останавливается до
изменений, обе оценки сохраняются. Обычный импортированный профиль переносит
историю на единый person_id. Внешний SMTP для проверки новых студентов отложен.

Проверка выпуска: **343 теста прошли без пропусков**, Ruff/форматирование пройдены.
Собранный wheel сверен с исходниками; закреплённые тексты/изображения сохранили
контрольные суммы. Дополнительно проверен настоящий dispatcher: немедленная
фиксация оценки, текстовый ответ после перезапуска, частный отчёт лидера и
явное согласие на API-привязку без автоматической записи/посещения.
