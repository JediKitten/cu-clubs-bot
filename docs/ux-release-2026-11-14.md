## Реализованный пакет

- Дата и время вводятся разными шагами, для начала, окончания и срока регистрации.
  Даты: `14.11.2026`, `14/11/26`, `14-11-2026`, `2026-11-14`, `14/11`,
  `14 ноября`, `сегодня`, `завтра`, `послезавтра`. Без года используется год
  начала встречи либо текущий год, указанный в подсказке. Относительные слова
  всегда относятся к сегодняшнему дню по Москве, не к дате встречи.
- Время: `19:30`, `19.30`, `19 30`, `1930`, `19` (19:00); всё по Москве.
  Невалидные часы/даты не угадываются. Старый совместный ввод вроде
  `14.11.2026 19:30` также принимается в шаге даты.
- Изменение начала ведёт к окончанию и сроку регистрации, затем к общей сводке.
  Длительность и интервал до закрытия записи предлагаются из текущей встречи;
  для нового черновика без длительности предлагается два часа. Это предложение,
  которое надо явно принять либо заменить. Ночная встреча имеет явную дату конца.
- До общего подтверждения меняется только состояние диалога. Сохранение всех
  связанных дат — один доменный вызов с проверкой роли и версии; один пересмотр
  приглашения партнёру/один набор уведомлений. Отмена не переносит встречу.
- Назад возвращает по временным шагам, сохраняя введённые значения. Возврат
  к предыдущему текстовому шагу мастера также сохраняет предложение расписания.
  После сохранения временного блока создание продолжается с площадки.
- Редактор встречи: пять групп вместо 14 полей на одном экране; внутри группы
  два-три поля и возврат к группе/карточке. Прямые старые кнопки полей работают.
- Правка клуба: после сохранения доступны следующее поле, выбор другого поля и
  завершение. В последовательном режиме Назад возвращает к предыдущему полю;
  при обычном входе из списка — в список. Из предпросмотра можно вернуться к вводу.
  Каждое поле сохраняется отдельно: отмена следующего поля не отменяет уже сохранённые.
- Ошибки ввода расписания/полей клуба оставляют пользователя в текущем диалоге.
  Неожиданный текст при наличии сохранённого экрана повторно показывает его,
  вместо неявного перехода в главное меню. Явные `/start` и `/menu` открывают меню.

## Что не объявляется завершённым

UX-аудит шире этого выпуска: возвраты из всех auth/QR/import-подшагов, группировка
шаблонов/редких админских действий и единый общий черновик всей карточки клуба
остаются отдельными запросами в аудите. Полная проверка каждой кнопки в живом
Telegram не заменяется чтением кода; здесь проверены указанные сценарии тестовым
транспортом и настоящим изолированным PostgreSQL.

Исходные карточки, ресурсы и баннеры не менялись. Новые подсказки даты/времени и
навигация — прямое UX-исключение владельца к прежней совместимости текстов.
