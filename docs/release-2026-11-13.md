# Выпуск 13 ноября: завершение начатых функций

По указанию владельца завершаем текущий пакет и разворачиваем его в тестовом
боте. Новые подсистемы в этот пакет не добавляем.

## Состав

- Один рабочий экран в личном чате: редактирование сообщения, удаление принятого
  ввода, восстановление после перезапуска, перелистывание длинных карточек.
  Telegram может запрещать удаление старых сообщений; неизвестную историю чата
  Bot API прочитать не позволяет. Файлы резервных копий остаются отдельными.
- Новый баннер главного меню, явно предоставленный владельцем вместо прежнего.
  Исходник 5120×5120 сохранён; для отправки как фото подготовлена копия 2560×2560
  из того же изображения. Прежний исходник также сохранён для истории.
- Подтверждение студенческой почты: ФИО, логин Тайма, код, срок и ограничения
  повторов/попыток, возврат к исходному действию. До настройки отправителя код
  не выдаётся в интерфейсе и профиль не становится подтверждённым.
- Создание клуба администратором, выбор уровня, назначение подтверждённого
  лидера; изменение уровня и лидера с повторной проверкой прав.
- Черновики встреч, поля и предпросмотр, публикация, открытый недельный список,
  закрытые ссылки, запись/отмена, список своих встреч, правки/перенос/отмена
  встречи. Лимит предварительной записи защищён от параллельного последнего места.
- Согласование совместной встречи партнёром, актуальность приглашения и общая
  регистрация. Новые уведомления проверяют актуальную доступность перед отправкой.
- Входящие Telegram updates в рабочей конфигурации шифруются до записи в БД,
  чтобы введённые коды не сохранялись открытым текстом. Ключ хранится в окружении.
  Его нужно сохранять при переносе/восстановлении, не менять при обычном выпуске.
  Ограничения фото: [Telegram Bot API](https://core.telegram.org/bots/api#sendphoto).
  Шифрование: [Fernet](https://cryptography.io/en/stable/fernet/).

## За пределами пакета

Синхронизация Google Sheets, QR и посещаемость, Excel, опросы и аналитика,
публичный интеграционный API и полный плановый дайджест/напоминания остаются
следующими этапами. Подключённый Google OAuth не означает готовую синхронизацию.

Рабочий почтовый отправитель пока не настроен: владелец отложил DNS. Поэтому
реальная проверка почты остаётся внешне заблокирована. Bootstrap Киноклуба
сохраняет ранее разрешённое исключение; новых подтверждённых пользователей
административным флагом не создаём.

## Приёмка

Перед выпуском: миграции на отдельной БД, полный pytest с PostgreSQL, Ruff,
проверка содержимого пакета, независимое сравнение общих сценариев с legacy.
На сервере: предварительный dump, обновление только `cu-clubs-test`, контроль
здоровья API/worker и наличия нового баннера. Секреты и Google-том сохраняются.

Локальная приёмка завершена: 207 тестов с PostgreSQL прошли без пропусков,
Ruff и форматирование прошли. Независимый guard повторил полный прогон и снял
блокирующие замечания; результаты сохранены в карте совместимости. В собранном
wheel проверены все 14 контрольных сумм медиа/текстовых ресурсов.
