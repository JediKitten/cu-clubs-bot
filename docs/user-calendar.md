# Календарь пользователя и контакт встречи

Исходники пакета 16 ноября 2026; выкладка и ручная приёмка Telegram фиксируются
отдельно. Новые операции не отправляют сообщения во внешние системы сами:
файл передаёт существующий транспорт Telegram после проверки доступа.

- «Мероприятия» открывает текущую московскую неделю с прежним legacy-заголовком
  `events_list` и исходным баннером Events. Соседние недели ограничены ±260.
  «По клубам» показывает клубы только с открытыми опубликованными/проведёнными
  встречами этой недели, включая принятого соорганизатора. Закрытые встречи,
  черновики, ожидающие партнёра и отменённые встречи в фильтр не попадают.
  Фильтр сохраняется при смене недели; «Все клубы» его сбрасывает. Список и
  выбор клуба разбиты по восемь кнопок. Возврат из карточки сохраняет неделю,
  клуб и страницу списка.
- «Мои встречи» сохраняет legacy-заголовок `my_events_list` и явно разделяет
  «Предстоящие» и «История». Предстоящая встреча ещё не закончилась; проведённая,
  отменённая или закончившаяся относится к истории. Учитывается активная
  предварительная запись из любого источника либо фактическое посещение
  (QR, ручная отметка, импорт), в том числе без предварительной записи.
  Отмена своей записи убирает встречу из списка, если посещения не было.
  Фактический посетитель сохраняет доступ к закрытой карточке своей истории.
- «Экспорт в календарь» сохраняет точную legacy-подпись `event_export` и текст
  `event_exported_text`. ICS доступен для опубликованной, проведённой или
  отменённой карточки после повторной проверки `EventService.get_event`.
  Закрытая встреча требует прежнего права: записи, посещения, команды или
  прямой ссылки. Самовольный вызов callback по ID права не добавляет.
  В файле стабильный UID, версия SEQUENCE, даты UTC, актуальное место,
  публичные описание/клубы/контакт, CLASS PRIVATE для закрытой и STATUS CANCELLED
  для отменённой встречи. Личные данные автора/участников, ссылка-приглашение
  и текст после регистрации не экспортируются.
- `public_contact` — отдельный явно заданный публичный контакт ответственного,
  строка до 300 символов, по умолчанию пустая. Источник — ввод организатора
  или API, без автоматического копирования ФИО, логина, почты или Telegram ID
  автора/лидера. Ввод предупреждает, что контакт виден всем с доступом к карточке.
  Он выводится после целого исходного блока карточки с HTML escaping, сохраняется
  в шаблоне, доступен в предпросмотре и правке шаблона. Пустая строка его убирает.
  Миграция `20261116_0013` заполняет существующие встречи пустым значением.

Общие правила и запросы находятся в `events.py` и `user_calendar.py`; Telegram
использует `calendar_user_ui.py` через существующий `handle_events`. API использует
то же валидируемое поле и явный DTO allowlist; новых HTTP-маршрутов ICS пока нет.
API-календарь уже поддерживает открытый фильтр `club_id` через `public_events`.
