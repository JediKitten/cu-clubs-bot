**Текущая справка, 22 ноября 2026.** FAQ реализован и установлен в действующем
`@cu_clubs_app` на прежнем сервере (`b6d4531`; код сверен побайтно). Сам справочник
ЦУ последний раз проверялся **16 ноября**, дата источника не обновляется датой
этой редакции. [Общий статус](project-status.md), [карта маршрутов](ux-map.md).

**Граница инструкции входа.** Сейчас включён Яндекс: категория → ФИО → вход
университетской почтой → «Проверить вход» → подтверждение привязки в Telegram.
Ресурс FAQ пока выбирает инструкцию регистрации только между временной
саморегистрацией и общим verified-путём (`faq.bot_entries`/`faq_ui._entries`);
отдельной ветки текста под Яндекс нет. При действующем test-флаге
саморегистрации FAQ может показать инструкцию ручного ввода ФИО/логина, хотя
гейт уже ведёт в Яндекс. Общий verified-текст тоже не описывает OAuth по шагам.
Это открытое согласование справки с текущим входом,
а не изменение политики доступа. [Точный путь входа](yandex-login.md).

Ручные проверки полного/контекстного FAQ, возвратов к клубу/встрече и актуальности
внешних ссылок командой остаются в приёмке. Ниже — устройство реализации и
исторические результаты автоматических проверок; в этой редакции их не запускали.

Модули и интеграция подготовлены 16 ноября 2026. Справочник хранится отдельно от маршрутов
и прав в `src/cu_clubs/faq_resources/ru.json`: версия, дата проверки, источник,
разделы «Про клубы», «Уровни клубов», «Как пользоваться ботом».

Каждый экран содержит видимую ссылку и отдельную кнопку на статью
[«Студенческие клубы»](https://note.cu.ru/at/e6a6a602-ddfb-4252-9659-0ac57cfb2a7c).
Вход из главного меню открывает все разделы справочника. Контекстный вход
показывает только соответствующий раздел и сохраняет возврат на исходный экран.
«Что даёт уровень?» показывает именно текущий назначенный уровень клуба;
«Назад» ведёт к его публичной карточке. Вход `faq:levels` из прежних сообщений
учитывает сохранённый `club_origin`. Старый callback из другого раздела не
расширяет контекстный справочник; полный FAQ открывается из главного меню.
В контекстном ботгайде вопрос возвращает к списку своих вопросов, затем
«Назад» ведёт к исходному экрану. В Telegram `handle_faq` вызывается до
остальных диалогов; прежняя устаревшая inline-справка удалена.

Ботгайд описывает реализованное поведение: каталог и открытые недели,
фильтр по клубам, свои предстоящие/история, ICS, отмена записи, оба QR,
опросы, подписки и явно опубликованный ответственный контакт. Инструкция
по первой записи выбирается тем же флагом, что и общий `access` service:
временный путь категорий/ФИО/логина не выдаётся за проверку почты, строгий
путь требует подтверждения. Справка не меняет политику доступа.

Источник проверен **16 ноября 2026**: ведущий исполнитель прочёл живую статью
в авторизованном браузере, включая раскрытые вопросы FAQ, скачал оригинальную
таблицу уровней; таблица отдельно визуально сверена вторым исполнителем.
Прямое чтение web-инструментом не сработало, это не выдаётся за источник текста.
В ресурс внесены краткие парафразы: три направления, создание клуба/«Импульс»,
Gate Review, обязательность участия, вступление в команду и «Выдающийся клуб»;
пять уровней с условиями и возможностями. Строгие пороги времени/CSAT сохранены,
вариативный охват X не заменён вымышленным числом, возможности не объявлены
автоматически накопительными. Ссылка на Ясю в Тайме и заявка «Импульса» взяты
из той же прочитанной статьи. `handbook.clubs` хранит `{question, answer, action?,
external_links?}`, `handbook.levels` — `{name, answer}`, `verified_at` — дату
сверки. Тексты plain text, UI экранирует HTML. Если дата проверки отсутствует,
разделы хендбука безопасно показывают только ссылку.
