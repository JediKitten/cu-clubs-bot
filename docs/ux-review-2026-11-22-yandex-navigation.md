# Яндекс: исправление устаревших кнопок

Причина: активный вход принимал обычную навигацию за `ya:*`, поэтому
кнопка «В меню» после ошибки повторяла ту же ошибку.

Исправлено только условие маршрутизации. Тексты и кнопки не менялись.
Проверены menu/profile/auth/category из трёх шагов, свежая кнопка выбора
категории и цепочка старая кнопка → отказ → меню → новый вход.
Старые/чужие nonce по-прежнему отклоняются, подтверждение учётки не ослаблено.

16 целевых тестов и Ruff/format прошли. Независимый UX review: approve.
Эти unit-тесты не заменяют повторную сквозную проверку владельцем после выкладки.
