# Общий предпросмотр правок клуба

Локальный пакет 16 ноября 2026. В существующем меню настройки профиля добавлена
кнопка «Изменить несколько полей». Прежние одиночные сценарии, их исходные
подписи, подсказки и основной блок карточки сохранены.

Новый путь: выбрать поле → ввести значение → увидеть общую карточку и сводку
всех подготовленных полей. «Изменить ещё» возвращает к выбору поля; «Назад»
из предпросмотра открывает последнее поле, из ввода — список полей.
Введённые значения и ошибочный сырой ввод хранятся в PostgreSQL Conversation,
переживают перезапуск dispatcher и не исчезают при этих возвратах. Выбор
того же поля показывает сохранённый ввод. «Отменить» удаляет подготовленную
пачку, не меняя клуб. Только «Сохранить изменения» применяет её целиком.

Разрешены шесть уже редактируемых полей: название, описание, канал/ссылка,
обложка, публичная команда и направление. Публичная команда остаётся описанием,
не выдаёт доступ. Уровни, лидер, участники с правами и организаторы не входят
в общую пачку. Проверка ссылки и фото использует прежний parser: нормализация
@username/HTTPS и уже полученный Telegram file_id. Новых сетевых операций
внутри транзакции нет; media resolver этим модулем не меняется.

`ClubService.update_profile_fields` повторно проверяет право редактирования
и исходную версию под блокировкой клуба. Все поля проходят прежнюю общую
валидацию/аудит `update_club` внутри savepoint: ошибка позднего поля откатывает
все предыдущие изменения и их записи аудита, оставляя пользовательский черновик.
Версия увеличивается по прежнему правилу каждого изменённого поля.

Если другой редактор уже изменил карточку, пользователь видит конфликт
с текущими значениями и своими предложениями. Черновик остаётся. «Проверить
с актуальной карточкой» явно обновляет основу, показывает новый общий
предпросмотр и требует нового подтверждения. Старые кнопки не применяют
пачку; отзыв права между предпросмотром и сохранением запрещает запись.

Проверки `tests/test_club_edit_batch.py` используют настоящую изолированную
PostgreSQL и mock Telegram dispatcher: all-or-nothing с ошибкой позднего поля,
один победитель конкурентных версий, общая сводка без промежуточных записей,
сохранённый ошибочный ввод/Back/restart, конфликт и новое подтверждение,
отмена, отозванное право и запрет расширения на уровни/права. Живая приёмка
Telegram и выкладка подтверждаются отдельно от автоматических проверок.
