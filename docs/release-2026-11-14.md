# Выпуск 14 ноября: Sheets, посещение и ведомости

Этот документ заменяет прежние статусы аудита 13 ноября. Полная v1 ещё не сдана.
Публикуется весь реализованный пакет в тестовый бот `@cu_clubs_app`.

## Добавлено

- Личный QR посетителя и общий QR встречи, отзыв/обновление, подтверждение отметки,
  проверка прав организатора, одна отметка независимо от источника. QR работает
  до отзыва без временного окна; вместимость предварительной записи не ограничивает
  фактическое посещение. Обычная ссылка карточки не отмечает посещение.
- Гостевой QR-путь: ФИО и Telegram ID, без почты и предварительной записи.
  В коллаборации достаточно одного клуба Seed+. Личный QR есть в профиле;
  общий QR, ручная отметка и файлы — в разделе посещаемости карточки встречи.
- XLSX-шаблон, загрузка, предпросмотр с ошибками по строкам, разрешение конфликтов
  ФИО, повторяемое подтверждение. Выгрузка посетивших либо всех участников,
  включая неявки и историческую пометку наличия профиля при первой отметке.
  Файлы остаются отдельными вложениями, навигация сохраняет один рабочий экран.
- Позднее подтверждение импортированного студента объединяет профиль и историю,
  не переписывая исторические признаки первой отметки. Проверка самой почты
  всё ещё требует отложенного отправителя.
- Завершение прошедшей встречи и поздние отметки/импорт; подтверждённый импорт
  после окончания фиксирует проведённую встречу.
- Google Sheets: привязка одной ячейки к встрече, запись опубликованной встречи,
  перенос/отмена, обратное изменение аудитории, обнаружение ручных конфликтов,
  повтор после сбоя. В админском «Календаре» доступны статусы, назначение комнаты,
  конфликт и явный выбор версии. Регистрация не зависит от доступности Google.
- Распознавание перехода собственной привязанной ячейки в цвет дайджеста и
  уведомление её лидеров. Это ещё не полный недельный процесс дайджеста.
- Назначение лидера и организатора по ID или известному @тегу. Человек должен
  хотя бы раз открыть бота; неизвестный тег не угадывается. В тестовой среде
  временно разрешён лидер без подтверждённой почты, без изменения статуса почты.
- Сохраняются предыдущие функции: клубы/подписки/права, события/коллаборации,
  регистрация/отмена, шаблоны с временем и длительностью, исходные баннеры и тексты.

## Проверка и пределы календаря

Итоговый полный прогон: **264 теста прошли, без пропусков**; Ruff и форматирование
прошли. Проверки используют изолированные схемы PostgreSQL и офлайн Telegram.
Сквозной тест проходит реальный dispatcher: гостевой QR → отметка без регистрации,
загрузка Excel → предпросмотр → подтверждение → чтение выгруженной ведомости.
Независимый guard проверяет совместимость и негативные сценарии доступа.

Реальный Google API проверен на выделенной тестовой копии: временная запись,
условное обновление, сохранность формата/соседних ячеек и удаление проверочной
записи с восстановлением исходного содержимого. Рабочая книга не изменялась.

Запись календаря ограничена средой test и совпадением явно разрешённого ID книги.
Новый год/недостающие недели автоматически не создаются. Последний блок без
следующего заголовка даты не используется: вместо записи наугад показывается
ошибка. Чужие формулы, защищённые/объединённые ячейки и rich text не перезаписываются.
Изменение занятого простого текста использует условную замену; Google API не даёт
универсальной атомарной проверки всей ячейки. Для первоначального выделения слота
и заметок остаётся узкая гонка одновременной ручной правки. Поэтому выпуск
предназначен для тестовой копии; рабочее подключение требует отдельной приёмки.

## Что ещё довести в начатых подсистемах

1. Календарь: полный процесс дайджеста, включая историческую инициализацию,
   готовность недели, позднюю публикацию и предупреждение о Ясе; работа с новым
   годом/неполной разметкой (владелец создаёт годовой лист вручную), настраиваемый
   цвет в админке и согласованная политика одновременных ручных правок.
2. Встречи/профиль: отдельный ответственный контакт, направление клуба и ближайшие
   открытые встречи в карточке; фильтр «По клубам», история/предстоящие встречи,
   выгрузка ICS. Анкета встречи зависит от будущего модуля опросов.
3. Доставка: напоминания за сутки/час, пятница 16:00, ручная рассылка с предпросмотром
   и количеством адресатов, полный кабинет ошибок/повторов. Уточнить адресатов
   уведомлений коллаборации и сократить уведомления о несущественных правках.
4. Эксплуатация: восстановление полного набора новых данных из резервной копии,
   контроль сроков OAuth, переход с тестового polling на штатный HTTPS/webhook,
   полная сквозная приёмка двух независимых клиентов после реализации API.
5. После тестирования убрать исключение для неподтверждённых лидеров.

## Что вообще не начинали

- Опросы после посещения: версии анкет, оценка 1–5, дополнительные вопросы,
  приглашения/продолжение, сохранение первой оценки.
- Аналитика клубов и университета: CSAT, охват, доходимость, отчёты по периодам
  с однократным учётом коллабораций. Границы семестров пока только утилита.
- Публичный API для клубных ботов: ключи/scopes/отзыв, привязка пользователя,
  `/api/v1`, идемпотентность/версии, журнал изменений, подписанные webhooks,
  независимый пример клиента. Наличие HTTP health/webhook Telegram не заменяет API.

## Отложено владельцем

Полный FAQ и рабочий почтовый отправитель/DNS. Почтовые коды не показываются
в чате и не заменяются фиктивным подтверждением. Новым студентам предварительная
запись будет доступна после подключения отправителя и настоящей проверки почты.
